# thap-sang-ban-do-vn-tiktok-live

Overlay TikTok LIVE "Thắp Sáng Bản Đồ Việt Nam": người xem comment tên tỉnh, thành quê mình để thắp đèn trên bản đồ 34 tỉnh, thành.

## Chạy

```
npm install --omit=dev
node server.mjs
```

Hoặc bấm đúp `CHAY.bat` (Windows). Bảng điều khiển: http://localhost:3002/control.html

> Thư mục `data/` (key API, token, key bản quyền, dữ liệu người xem) và `node.exe` không được đưa lên git.
